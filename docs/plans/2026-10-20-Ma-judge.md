# M-a judge 判决插件 + sink_archive 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 引擎新增 `judge` 判决插件（六规则 DSL v1 + persist 去抖状态机）与 `sink_archive` NG 存档插件，安全帽工程板端跑通"检出框 → OK/NG 判决 → 证据落盘"闭环。

**Architecture:** judge 的规则求值与 persist 状态机做成可单测的纯逻辑（`JudgeCore`），IStage 壳只做参数解析与 Frame 读写；verdict 写入 `Frame`（新增字段），`image_out` 透传到结果 JSON、`sink_archive` 读它落图、`Execute` 聚合进 RunStats 出现在 summary。schema v1 不改（params 本就透传），无 judge 段的工程行为不变。

**Tech Stack:** C++17 / nlohmann/json / OpenCV（imwrite）/ plain-assert + ctest（沿用 M0 约定）。

**Spec:** `docs/2026-10-18-工业工作流设计.md` §2（judge DSL/动作/状态机）、§6（schema v2 增量）、§8（插件清单）。

## Global Constraints

- C++17、无新第三方依赖；`Detection`/`Frame` 只加字段不改旧字段（旧测试不动仍须绿）
- 规则语义 v1 定死：**score/size/region = 过滤器**（按数组顺序逐步收窄 detections）；**count/persist/regex = 判决规则**（对过滤后结果评估，命中=违规）
- verdict：`ANY_NG`（默认，任一违规→NG）/ `ALL_OK`（全部无违规才 OK；v1 两者结果一致，字段为模板 C 预留）
- persist 语义：连续 `frames` 帧"过滤后有检出"计数 +1；某帧无检出即清零；达阈值置违规并锁存
- v1 拒绝 `plc_write`/`http` 动作（Init 报错，M-c 实现）；`snapshot`/`log` 可用
- `gold_regression` 测试必须保持绿（judge 插入不改 detections）
- 板端验证目标：e6e8b86e04c61b88（RK3576，驱动 v0.9.8，helmet 2.x 模型可用；2.3.2 工具链 yolov8n 不可用——与本计划无关，勿在该板跑 COCO 工程）
- 板端构建环境变量 `~/.bashrc` 尾部对非交互 shell 无效（interactivity guard），命令里必须内联 export 四个 RVS/NDK 变量

## Review Focus

1. **region 多边形退化输入**：点数 <3 的 polygon、凹多边形——ray casting 对 <3 点应 Init 报错而非崩溃（Task 2 测试钉住）
2. **count 通配 `class:"*"`**：统计全部检出而非按类分桶（Task 2 测试钉住）
3. **无 post 段/零检出的工程**：judge 恒 OK、不崩、persist 不误置位（Task 4 测试钉住）
4. **ng_dir 不可写**：sink_archive stderr 告警但 Process 返回 true 不阻断流水线（Task 5 测试钉住）
5. **检测框负坐标/越界框的中心点**：region 用原始中心点判定，不做 clamp（与 image_out 忠实写出的职责划分一致，Task 2 测试钉住）

### Task 2: JudgeCore 规则求值（纯逻辑，过滤器+判决规则）

**Files:**
- Create: `engine/stages/judge.hpp` / `engine/stages/judge.cpp`
- Test: `engine/tests/test_judge.cpp`（新建）

**Interfaces:**
- Produces:
```cpp
struct JudgeRule {
    std::string type;            // count|score|size|region|persist|regex
    std::string cls = "*";       // 通配
    int min = 0, max = INT_MAX;               // count
    float thres = 0.f;                        // score
    float min_px = 0.f, max_px = FLT_MAX;     // size
    std::vector<cv::Point2f> polygon;         // region（<3 点 Init 报错）
    bool inside = true;                       // region
    int frames = 1;                           // persist
    std::string pattern;                      // regex
};
struct JudgeVerdict { bool ng = false;
    nlohmann::json detail;                    // {"violations":[{rule,type,cls,actual}...],"filtered":N}
    std::vector<int> persist_counters;        // 状态机外置，Task 3 使用
};
struct JudgeCore {
    static std::vector<JudgeRule> ParseRules(const nlohmann::json& rules); // 非法抛 runtime_error
    static std::vector<Detection> ApplyFilters(const std::vector<JudgeRule>& rules,
                                               const std::vector<Detection>& in);
    // persist_counters 由调用方持有并回传（帧间状态）
    static JudgeVerdict Evaluate(const std::vector<JudgeRule>& rules,
                                 const std::vector<Detection>& detections,
                                 std::vector<int>* persist_counters);
};
```
- 过滤顺序 = rules 数组顺序；region 判定用框中心点 ray casting，不做 clamp
