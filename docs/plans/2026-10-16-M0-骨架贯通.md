# RKVision Studio M0 骨架贯通 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 打通"工程包 → 板端引擎装配运行 → 结果回拉 → 金标准比对"全链：RK3576 上安全帽检测与 mydemos/algorithm-helmet demo 检测框逐框一致（IoU≥0.98、置信度 |Δ|≤0.01），E2E ≤60ms/帧。

**Architecture:** 板端 C++ 引擎读 `pipeline.json` 从静态注册表装配 Stage 链（source→preprocess→infer→postprocess→sink），核心代码平台无关、host（WSL x86）可编译跑单测，librknnrt 调用隔离在 infer 一个文件里；PC 端 Python CLI（rvs）负责打包/部署/拉取/比对。数值复刻以 mydemos/algorithm-helmet 源码为唯一真值。

**Tech Stack:** C++11（引擎）、nlohmann/json（单头 vendored）、OpenCV（板上用 sysroot 库、host 用 libopencv-dev）、CMake+ctest、Python3+pytest（studio）、adb。

**Spec:** `docs/2026-10-16-框架设计.md`（本计划与其 §10 审查问答配套阅读；冲突处以本计划为准，已注明两处修正，见 Global Constraints）。

## Review Focus

1. **非对称原图的 lround 舍入**：demo 注释实证 798×1200 时 425.6→426，截断会差 1px 且张量全图微差。预期：letterbox 尺寸用 `lround`。测试见 Task 6 步骤 1（798×1200 合成图断言 new_w=426）。
